# 外部 embedding API 选型 · 实测对比

> 日期：2026-09-02
> 中转 API：`https://api.chatanywhere.tech`（OpenAI 兼容）
> 测试方法：对同一组中文样本请求 embeddings，算余弦相似度，测维度/延迟。

---

## 1. 中转 API 提供的 embedding 模型（实测）

`GET /v1/models` 过滤 embedding 类，仅 3 个，**均为 OpenAI 系**：

| 模型 | 维度 | 说明 |
|------|------|------|
| `text-embedding-3-small` | 1536 | 可 `dimensions` 裁剪 |
| `text-embedding-3-large` | 3072 | **已锁定全维度（开发期不切换维度）** |
| `text-embedding-ada-002` | 1536 | 旧模型，不可裁剪 |

**无** BGE / M3E / jina / nomic / mxbai 等国产或本地优化中文模型。

---

## 2. 中文语义分辨力实测（核心指标）

样本：A=`CentOS 云服务器 1c2G 内存受限`，B=`腾讯云 WebDAV 存储同步`，C=`早餐吃鸡蛋和牛奶`，A'=`服务器 CPU 资源紧张`（A 的近义变体）。

| 模型 | sim(A,A') 近义 | sim(A,B) 相关 | sim(A,C) 无关 | 分辨力（近义−无关） |
|------|:---:|:---:|:---:|:---:|
| **text-embedding-3-small** | ~0.49* | ~0.33 | ~0.19 | ≈0.30 |
| **text-embedding-3-large** | 0.572 | 0.330 | 0.131 | **0.44** ✅ |
| **text-embedding-ada-002** | 0.860 | 0.787 | **0.731** | **0.13 ❌** |

\* small 单样本实测 0.4931（批量时端点不稳，见 §4）。

**结论：ada-002 直接排除**——无关文本余弦也高达 0.73，判定阈值完全无法区分「相同/相关/无关」。**large 分辨力最佳（0.44）**，small 居中（≈0.30）。

---

## 3. 与其它候选方案的对比

| 方案 | 中文效果 | 本机成本 | 网络 | 隐私（数据出域） | 结论 |
|------|:---:|:---:|:---:|:---:|------|
| **本中转 large**（现成 key） | 优（0.44） | 已有 key，按 token 计费 | 本机已通（直连+代理均可） | 记忆内容发往中转 | ✅ 首选 |
| 本中转 small | 良（0.30） | 更低 | 同上 | 同上 | 备选（端点不稳） |
| 阿里百炼 qwen-embedding | 优 | 需注册+新 key | 国内直连 | 出域 | 可选，需新开账户 |
| 本地模型（1c2G） | — | 内存不够 | — | 不出域 | ❌ 已排除（跑不动） |
| 字符 n-gram 相似度（离线降级） | 中（词面匹配） | 0 | 无 | 不出域 | 降级兜底，非语义 |

---

## 4. 运营风险（实测发现，重要）

1. **`small`/`ada-002` 端点极不稳**：批量请求 6 次连续返回空响应（`len=1`），`large` 稳定。→ **生产中选 large，且 CLI 必须做重试 + 失败降级**。
2. **`large` 3072 维**：已决定**开发期固定全 3072、不切换维度**（锁定一个最好模型开发，避免中途改向）。
3. 单次中文 4 句 ≈ 60 token，large 延迟 ~2.6s/批 → 每任务调用次数受预算约束（见计划）。

---

## 5. 推荐结论（待确认）

- **首选模型：`text-embedding-3-large`，固定全 3072 维**（开发期不变更）
- 理由：现成 key 零新增、中文分辨力最佳（0.44）、语义判定阈值可落地（相同≥0.55 / 相关≥0.40 / 无关<0.25，需用真实记忆校准）
- **兜底：端点失败自动重试 → 重试仍失败 → 降级字符 n-gram**（保证流程不断链）
- 隐私提示：记忆文本会发往中转 API，若对敏感记忆有顾虑，可在嵌入前对正文做轻量脱敏或仅嵌标题
